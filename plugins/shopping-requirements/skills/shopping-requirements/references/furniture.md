# Furniture — criteria, metrics, benchmarks

Format per category: criterion → metric → benchmark (unqualified / acceptable / good).

## 沙发 Sofa

- **耐久性 Durability (坐垫填充)** → 海绵密度,单位 D (kg/m³) → <25D 一年内明显塌陷,不合格;
  ≥30D 及格线;35–40D 为高回弹海绵,家用主力位建议这个区间;40D+ 多用于高端款,过软或过硬
  都要结合手感,不是越高越好但不能低于30D。
- **承托结构 Suspension** → 弹簧类型 → 弹力带(松紧带)最便宜但塑形差、易松弛;蛇簧
  (serpentine spring)常规够用;独立袋装弹簧承托最好、也最贵。避免"三无"填充说明的款式。
- **框架材质 Frame** → 材质 → 刨花板/密度板框架易开裂,不合格；生态板/多层实木夹板可接受；
  全实木框架(如樟子松、橡胶木)最耐用,注意含水率应做过窑干处理(含水率<12%)。
- **面料耐磨度 Fabric abrasion (布艺款)** → 马丁代尔耐磨测试(Martindale)次数 →
  <10,000 次不适合家用日常使用;15,000–30,000 次为家用及格线;30,000+ 适合高频使用/宠物家庭。
- **皮质等级 (真皮款)** → 皮料分级 → 看清"头层牛皮/半苯胺革" vs "二层皮/再生皮"标注,
  二层皮/人造革不耐用、易开裂,非必要不选。
- **环保 Formaldehyde** → 甲醛释放限量等级 → 板材应标明 E1 级(≤0.124mg/m³)及以上,
  E0 级更优;无标注或"复合板"未标级别的谨慎选择。
- **防潮防霉 Moisture/mold resistance** → 面料/海绵防霉等级 → 依据 GB/T 24346 纺织品
  防霉等级(0–4级,0级最优、4级最差)→ 无任何防霉说明的款式在梅雨季/潮湿地区坐垫夹层
  容易滋生霉菌和异味,不合格;标注防霉等级0-1级或有"防潮抗菌整理"说明为及格线,
  南方/沿海潮湿地区应优先选择。
- **尺寸 Dimensions** → 长×深×座高(cm)→ 按房间净宽减去至少 60cm 留出过道,并核对
  电梯/楼梯间/门洞净宽是否能让沙发主体或拆分件通过。

## 床架 Bed frame

- **承重结构 Support** → 排骨架间距(cm)→ 间距 >8cm 长期使用易导致床板断裂、床垫塌陷,
  不合格;≤7cm 为及格线;实木排骨架优于金属或塑料排骨架。
- **承重 Load rating** → 额定承重(kg)→ 标准双人床应≥300kg 动态承重(即两人+日常活动),
  低于此数值对成年人/多人使用不安全。
- **框架材质** → 材质 → 同沙发条目:避免纯刨花板结构件,优先实木或多层实木边框。
- **甲醛 Formaldehyde** → 板材等级 → E1 级及以上(同上),这一条对床类家具尤其重要,
  因为长时间近距离接触(睡眠 6-8 小时/天)。
- **防潮防霉 Moisture/mold resistance** → 木材含水率(%)+ 是否全封边 → 含水率超出
  当地平衡含水率 ±3%(参照 GB/T 3324 家具通用技术条件)会导致湿胀干缩、开裂或受潮膨胀,
  不合格;板材边缘未封边处会持续吸湿膨胀、发霉,务必确认全封边。带收纳箱体的床架
  (床箱式)尤其要确认箱体内部是否预留透气孔——密闭收纳格在潮湿地区容易积湿长霉,
  南方/沿海地区应优先选带通风设计的款式。
- **尺寸 Dimensions** → 外框长宽(cm)→ 与目标床垫尺寸(1.2/1.5/1.8m 宽 × 2.0/2.2m 长)
  匹配,并核对卧室净空、房门/走廊净宽是否能通过整床架或最大部件。

## 床垫 Mattress (若涉及)

- **软硬支撑 Support** → 弹簧类型/密度 或 海绵密度(记忆棉常见 50D 左右为家用及格线,
  <40D 偏软易塌陷)→ 具体依材质类型区分,连续簧/独立袋簧优于无簧全海绵款(独立袋簧减少
  两人睡眠互相干扰)。
- **甲醛/VOC** → 同上,E1 级及以上,记忆棉款注意闻是否有刺鼻气味(工艺不合格标志)。
- **防潮防霉 Moisture/mold resistance** → 透气性设计 + 抗菌整理 → 高密度记忆棉透气性差,
  潮湿地区或睡眠易出汗人群容易积湿滋生螨虫霉菌,不合格款式表现为长期使用后发闷、
  有异味;建议选开孔透气海绵、独立袋装弹簧(带透气层)或标注"防螨抗菌"整理
  (抗菌率 ≥90%,依据 GB/T 20944)为及格线,表布可拆卸清洗为加分项。
- **尺寸** → 与床架内框尺寸精确匹配(误差 <2cm)。

## 衣柜/储物柜 Wardrobe

- **板材环保** → 甲醛等级 → E1 级及以上,优先 E0。
- **五金件耐用度 Hardware** → 铰链/滑轨开合测试次数 → 优质铰链标称 ≥8 万次开合,
  劣质铰链用几个月就松动异响。
- **封边工艺 Edge banding** → 是否全封边 → 未封边或封边不严的板材边缘会持续释放甲醛,
  务必确认四面封边。
- **防潮防霉 Moisture/mold resistance** → 背板/侧板封边完整度 + 是否预留通风孔 →
  衣柜是家具中最易受潮发霉的品类之一——封闭空间+未封边的刨花板背板在潮湿地区数月内
  即可能鼓包发霉,不合格;应确认背板全封边、避免柜体直接贴墙安装(留1-2cm空隙或选带
  通风孔设计的款式)为及格线,南方/沿海潮湿地区尤其要重视此项,五金件(铰链/滑轨)
  也应确认为不锈钢材质而非普通铁质,避免潮湿环境生锈。
- **尺寸** → 外框尺寸(cm)+ 是否需要定制以匹配墙面/层高。

## 餐桌/餐桌椅 Dining table (若涉及)

- **台面材质耐用度** → 材质 → 实木 > 岩板/大理石(耐磨耐高温但重、易崩边)> 三聚氰胺贴面
  板(便宜但怕潮怕刮)。
- **甲醛** → 同上,E1 级及以上。
- **稳定性 Stability** → 桌腿结构/承重 → 避免细金属单腿或纯玻璃台面无横档加固款,
  日常使用易晃动。
- **尺寸** → 长×宽×高(cm),按用餐人数(每人≥55-60cm 宽度)和房间净空核算。
