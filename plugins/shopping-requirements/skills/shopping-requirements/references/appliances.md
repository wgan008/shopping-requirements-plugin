# Appliances — criteria, metrics, benchmarks

Format per category: criterion → metric → benchmark (unqualified / acceptable / good).

## 洗衣机 Washing machine

- **能效 Energy efficiency** → 中国能效等级(1–3 级,1 级最优)→ 3 级为准入门槛(国标最低
  合格线);1 级能效最省电,长期使用电费差距明显,预算允许优先选 1 级。
- **水效 Water efficiency** → 用水效率等级(1–3 级)→ 同上,优先 1 级或 2 级。
- **电机类型/质保 Motor** → 电机类型 + 质保年限 → 普通有刷电机质保通常仅 1-3 年,易损坏;
  变频电机(直驱 DD 或皮带变频)质保普遍达 10 年,噪音更低、寿命更长,优先选变频且确认
  质保年限≥10 年。
- **噪音 Noise** → 洗涤/脱水分贝(dB)→ 洗涤 >52dB 或脱水 >75dB 偏吵,尤其影响紧邻卧室/
  客厅的安装位置;洗涤 ≤48dB、脱水 ≤68dB 为较优水平。
- **容量 Capacity** → 额定洗涤容量(kg)→ 按常住人口估算:1-2人 7-8kg;3-4人 9-10kg;
  5人以上或需洗床品建议 10kg+。容量不足会导致大件(被套/床单)洗不干净或超负荷损伤电机。
- **筒体材质 Drum** → 内筒材质 → 应为不锈钢内筒,塑料内筒(多见于低端老款)不耐用、易积垢。
- **安装尺寸 Fit** → 机身长宽高(cm)+ 进出水管位置 → 核对预留位置净空、门框宽度、
  排水管高度是否匹配,滚筒式尤其要确认柜体开口深度足够且预留散热/开门空间。

## 冰箱 Refrigerator

- **能效 Energy efficiency** → 能效等级(1–3 级)→ 3 级为合格线,1 级最优,冰箱是常年
  不间断运行电器,能效差距对电费影响比洗衣机更明显,尽量选 1 级。
- **制冷方式 Cooling type** → 风冷无霜 vs 直冷 → 直冷款需要定期手动除霜、易结冰,
  风冷无霜(风冷)款更省心,家用优先风冷无霜,除非是纯做冷藏的小型二级柜。
- **噪音 Noise** → 运行噪音(dB)→ >45dB 明显偏吵(尤其开放式厨房或冰箱靠近卧室);
  ≤38dB 为安静水平,变频压缩机款通常更低噪音。
- **容积 Capacity** → 总容积(L)→ 按常住人口估算:1-2人 200-300L;3-4人 300-450L;
  5人以上或有囤货习惯建议 450L+。
- **门体设计 Door layout** → 门数/开门形式 → 对开门/十字对开门利于分区存放但占用较大
  开门空间,需核对厨房净宽是否允许双开门完全展开(一般每侧门体开启需预留 60cm+)。
- **安装尺寸 Fit** → 机身宽×深×高(cm)→ 核对厨房预留位、入户门/电梯净宽净高(冰箱是
  大家电中最常因尺寸不合无法搬入的品类之一),并预留背部/顶部散热间隙(一般≥10cm)。

## 空调 Air conditioner (若涉及)

- **能效 Energy efficiency** → 能效等级(1–3 级)+ APF 值 → 3 级为合格线,1 级最优,
  空调是家庭夏季用电大户,能效等级直接影响电费。
- **匹数/制冷量 Capacity** → 匹数(如 1匹/1.5匹/2匹)对应房间面积 → 大致换算:1匹
  ≈10-15㎡,1.5匹 ≈15-20㎡,2匹 ≈20-30㎡,层高超 2.8m 或西晒房间需上调一档,选小了
  制冷/制热不足、压缩机长期高负荷运转更易损坏。
- **噪音 Noise** → 室内机运行噪音(dB)→ >28dB 影响睡眠,卧室用机优先选 ≤23dB 的
  静音款。
- **类型 Type** → 定频 vs 变频 → 定频费电、温度波动大,现在主流应选变频。

## 电风扇/冷风扇 Cooling fan (若涉及)

- **送风能力 Airflow** → 风量(m³/min)→ 普通台式/落地扇一般 20-40m³/min;循环扇
  (air circulator)强调远距离送风,标称风量 ≥45m³/min 才能有效带动整屋空气循环,
  低于此值只适合近距离直吹。
- **能效 Efficiency** → 风力效率(m³/min ÷ 功率W)→ 电风扇国内无强制分级能效标识,
  需自行用"风量÷功率"比较,数值越高说明同样耗电送风更远更强,劣质小电机机型这个比值
  明显偏低但商家不会主动标注,需要向卖家/AI导购索要实测风量数据。
- **噪音 Noise** → 各档位分贝(dB)→ 高档 >65dB 夜间使用会影响睡眠;低档 ≤40dB
  为卧室夜用及格线,循环扇/塔扇通常比传统落地扇更安静。
- **安全 Safety(有儿童/宠物家庭)** → 防护网格栅间距(mm)→ 间距 >12mm 手指可伸入触及
  扇叶,不合格(参照 GB 4706.1 家电安全标准);≤12mm 为合格线,无叶风扇/循环扇天然更安全。
- **摇头角度 Oscillation** → 水平摇头角度(°)→ <60° 覆盖范围小,建议 ≥90°,
  部分塔扇支持上下+左右双向摇头,覆盖范围更大。
- **类型 Type** → 落地扇 vs 塔扇 vs 循环扇 → 落地扇送风直接但占地大;塔扇占地小、
  外观简洁但风力通常较弱;循环扇专为空气循环/配合空调使用设计,不追求直吹凉感。
  按主要使用场景(直吹降温 vs 辅助空调循环)选型,而非单纯比风量数字。

## 洗碗机 Dishwasher (若涉及)

- **容量 Capacity** → 标准套数(套)→ 按常住人口估算:1-2人 6-8套;3-4人 8-13套;
  5人以上或常有聚餐建议 13-16套。套数不足会导致日常洗涤仍需分批手洗补充。
- **能效 Energy efficiency** → 能效等级(1–3级)→ 3级为合格线,1级最优,洗碗机是
  常用大家电,能效差距长期影响电费。
- **水效 Water efficiency** → 用水效率等级(1–3级)→ 优先1-2级,劣质机型单次耗水量
  可能是高效机型的2倍以上。
- **洗净能力 Cleaning** → 最高洗涤水温(℃)+ 喷淋臂覆盖层数 → 最高水温 <60℃ 难以
  有效去油污和杀菌;≥65℃ 高温洗为及格线,并确认至少双层喷淋臂覆盖(单层喷淋上层餐具
  常洗不干净)。
- **烘干方式 Drying** → 烘干技术类型 → 纯"余热烘干"(被动、依赖开盖散热)效果差、
  易有水渍残留,不合格；热风烘干或沸石(晶蜡)烘干为及格线及以上,沸石烘干效果最好但
  价格更高。
- **噪音 Noise** → 运行噪音(dB)→ >52dB 明显偏吵,尤其开放式厨房；≤45dB 为安静
  水平。
- **安装方式 Fit** → 嵌入式 vs 独立式/台式 → 嵌入式需要橱柜预留标准洗碗机位
  (通常宽60cm或45cm),需核对现有橱柜是否已预留或能否改造；无法改造橱柜的场景
  应选独立式或台式免安装款,并确认台面/水槽附近有摆放空间和取水排水条件。

## 咖啡机 Coffee machine (若涉及)

- **类型 Type** → 意式泵压 vs 美式滴滤 vs 胶囊 vs 全自动现磨(bean-to-cup)→
  按想喝的咖啡类型选型,不是同一套评判标准:要意式浓缩/拉花选泵压或全自动现磨款,
  只想每天一杯美式选滴滤款更省心,追求便捷可接受耗材成本选胶囊款。
- **萃取压力 Extraction pressure(意式/全自动款)** → 泵压(bar)→ 标称 <15bar 的
  机型在负载下往往无法稳定维持理想的 9bar 萃取压力,萃出的油脂(crema)不稳定,
  不合格线设在 <15bar；15bar 及以上为及格线(注意:标称bar是泵的最大压力,不等于
  实际萃取压力,但低于15bar的机型基本无法达标)。
- **锅炉/加热系统 Boiler** → 单锅炉(含热交换)vs 双锅炉 vs 思魔科(Thermoblock)→
  单锅炉/thermoblock 无法同时出咖啡和打奶泡,需等待切换,适合预算有限、不常连续
  出品的家用场景；双锅炉可同时萃取+蒸汽打奶泡,效率更高但价格显著上升,按使用频率
  决定是否值得升级。
- **研磨 Grinding** → 是否内置磨豆机(全自动款)→ 全自动现磨款需确认磨豆机为
  锥刀(conical burr)而非刀片式(blade)研磨,刀片式研磨颗粒不均匀、影响萃取一致性,
  不合格；锥刀/平刀磨豆机为及格线。
- **清洁维护 Maintenance** → 是否支持自动清洗/除垢程序 → 无自动清洗提示的机型
  长期使用易结垢影响出品和寿命,优先选带自动除垢提醒或清洗程序的款式。
- **水箱容量 Water tank** → 容量(L)→ 按家庭日常用量估算,<0.8L 的小水箱需要
  频繁加水,家用建议 ≥1L。

## 热水器 Water heater (若涉及)

- **类型 Type** → 储水式/即热式/燃气式 → 按用水人数、燃气条件选型,燃气式需确认
  排烟方式(强排式 vs 平衡式)与户型是否匹配。
- **能效 Energy efficiency** → 能效等级 → 电热水器/燃气热水器均有能效标识,优先 1-2 级。
- **容量/功率 Capacity** → 储水式看容积(L,按人口:1-2人 40-50L,3-4人 60-80L);
  燃气式看升数(如 12升/16升,对应可同时供应的用水点数量)。
- **安全 Safety** → 燃气式需确认带有防一氧化碳中毒/熄火保护装置(国标强制要求,
  但仍需在listing中核实标注,尤其二手房翻新场景)。
